## 中文

## 这是什么？

这是两份面向 Tavo 的小说式描写预设。它们共享相近的写作目标：把玩家本轮的戏内言行自然融入正文，减少重复前文，关注人物动作、情绪和场景细节，并尊重玩家已经确定的剧情方向。

它们不是模型升级，也不承诺让所有模型写出相同效果。实际表现仍取决于模型、API 服务、人物卡、世界书与上下文。

## 两个预设有什么区别？

### 伊芙琳·织境

**最初的自用原型：带有完整叙事人格的版本。**

伊芙琳是高位叙事人格「活着的编年者」——她默认在故事幕后工作，通过理解人物、关系、历史与场景来组织叙事，而不是每轮跳出来介绍自己。预设还包含面向明确成年虚构角色的亲密叙事指导。

- 保留独立的叙事身份与更细分的规则结构。
- 适合接受这种人格设定、希望使用完整原型的玩家。
- 亲密叙事指导只影响写作方式，不代表突破模型或服务商限制。

### 伊薇娅·织语

**后来整理出的中性版本：为适应不接受额外人格身份的中转站而设计。**

最初先有伊芙琳。后来，为了适应要求预设不带独立人格或身份设定的使用环境，我们保留共同的小说写作目标，整理出伊薇娅。

- 不设立独立叙事人格，采用更常规、简洁的提示词结构。
- 重点放在小说正文、剧情连续性与场景描写。
- 设计目标是尽量减少因额外人格设定产生的兼容顾虑；不同中转站和 API 的规则各异，仍应以服务商要求为准。

### 哪个更好？

两者的实际写作表现可能非常接近，差异并不保证每轮都明显。它们不是高低阶版本，也不承诺谁在所有模型上更强。

**简单选择：** 想保留伊芙琳的叙事人格与亲密叙事指导，选伊芙琳；希望使用不带独立人格身份、结构更中性的版本，选伊薇娅。

## 下载与安装

1. 前往 [GitHub Releases](https://github.com/AozoraCynthiAStudio/Aozora-Tavo-Novel-Presets/releases) 下载唯一的正式附件 **1.0.2.zip**。
2. 解压后选择需要的 JSON 文件：
   - 伊薇娅·织语_1.0.2.json
   - 伊芙琳·织境_1.0.2.json
3. 在 Tavo 中导入。建议先备份现有预设，再用自己常用的模型、人物卡和世界书测试。

## 兼容性与反馈

- 本项目是写作风格与叙事组织指导，不修改模型本身，也不绕过服务端限制。
- 伊薇娅的目标是中性、通用的结构；这不是对所有中转站或 API 的绝对兼容保证。
- 两份预设都不保证固定字数、第一人称视角或跨模型一致的输出。
- 欢迎提交可复现的问题与建议，反馈将作为后续迭代的参考。

本项目为独立社区项目，不是 Tavo 或任何模型服务商的官方项目。

## English

Aozora · Tavo Novel Presets contains two related presets for novel-style roleplay in Tavo. Both focus on integrating the player's latest in-story input into prose, maintaining continuity, and adding relevant scene details without taking over the player's choices.

- **Eveline Zhijing** is the original personal preset. It has a distinct backstage narrative persona, Eveline the “living chronicler,” plus guidance for intimate writing involving clearly adult fictional characters. It is not a method for bypassing model or provider restrictions.
- **Iveya Zhiyu** was created later for environments that do not accept additional persona or identity settings. It keeps the shared writing goals in a more neutral, conventional prompt structure.

Their output may be quite similar; neither preset is universally better. Choose Eveline if you want its narrative identity and intimacy guidance, or Iveya if you prefer a neutral structure without a separate persona. Compatibility depends on the model and provider, so follow the provider's rules.
